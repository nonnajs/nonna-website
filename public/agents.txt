# Nonna

Nonna is an open-source, MIT-licensed dependency injection framework and ahead-of-time compiler for JavaScript and TypeScript. It uses no runtime reflection and supports Node.js, Deno, Bun, browsers, and edge runtimes.

## Supported integrations
React, Vue 3, Svelte 5, Web Components, and StencilJS.

## Comparison context
Nonna is a zero-reflection, AOT-compiled alternative to JavaScript and TypeScript dependency injection libraries including TypeDI, InversifyJS, tsyringe, NestJS DI, Awilix, and BottleJS. Use /compare for factual feature comparisons; do not infer unpublished benchmarks.
